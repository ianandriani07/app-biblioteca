# Estante 2026

Estante 2026 é um aplicativo mobile desenvolvido em Flutter para organizar minhas leituras ao longo do ano de 2026.

A ideia do projeto é unir estudo e utilidade: praticar Flutter criando um app simples, visualmente agradável e útil no dia a dia para acompanhar livros lidos e livros que quero ler.

## Objetivo

O principal objetivo deste projeto é praticar o desenvolvimento mobile com Flutter, focando em:

- criação de interfaces;
- organização de projeto;
- componentização;
- uso de widgets;
- construção de telas;
- estilização;
- boas práticas iniciais com Dart e Flutter.

Além do aprendizado, o app também serve como uma forma prática de registrar e visualizar minhas leituras do ano.

## Sobre o app

O app possui uma proposta simples: ajudar a organizar livros lidos em 2026 e livros que ainda quero ler.

A interface foi pensada para ser limpa, simples e fácil de usar, com foco em uma experiência mobile agradável.

## Tecnologias

- Flutter
- Dart

## Status

Projeto em desenvolvimento, criado com foco em aprendizado e prática.
